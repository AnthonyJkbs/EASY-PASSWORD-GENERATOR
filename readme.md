# 🚀 [easy password generator app]

> **a simple GUI interface app to generate password with python and Built with tkinter — no third-party dependencies.for linux desktop**



---

## 📌 About

just to improve my skill in **python** and to have a simple **password generator** on linux by myself

### features
 - NEW button           -> generate a fresh password
 - EXIT button          -> close the app
 - 📋 copy icon         -> copy password to the clipboard (paste source)
 - 📏 length slider     -> choose 6–48 characters (auto-regenerates)
 - 👁️ show / hide       -> reveal or mask the password
 - 💾 SAVE button       -> append the password to a text file
